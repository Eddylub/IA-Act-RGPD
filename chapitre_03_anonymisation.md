# Le fichier est-il anonyme ?

**Non.** Remplacer les noms par des codes est une **pseudonymisation**, pas une anonymisation. La table de correspondance permet à l’hôpital de retrouver les patients, et l’équipe peut parfois les reconnaître sans cette table.

La réidentification peut être possible grâce à un code unique, des informations rares (maladie, traitement), des dates et lieux précis, des détails dans les comptes rendus ou le croisement avec d’autres sources.

Selon la CNIL, il faut vérifier qu’il est impossible d’**individualiser** une personne, de **corréler** ses données ou d’en **inférer** des informations sensibles. Tant qu’un risque raisonnable de réidentification subsiste, le fichier reste constitué de données personnelles et doit être protégé.

*Source : [CNIL, « L’anonymisation de données personnelles »](https://www.cnil.fr/fr/technologies/lanonymisation-de-donnees-personnelles).*
